⚡ โหมดเร็ว (Fast)

ความเสี่ยง: สูง 🔴
  • ยิงรัวที่สุดโดยไม่รอผลตอบกลับ
  • ใช้ Asyncio (ยิงขนานกัน)
  • ข้อดี: เร็วมาก กระหน่ำ SMS
  • ข้อเสีย: โดนแบน IP ง่ายมาก และอาจทำให้เน็ตค้าง

🔥 โหมดรัว (Super)

ความเสี่ยง: ปานกลาง 🟡
  • แนะนำ! ระบบอัจฉริยะ
  • การันตีความสำเร็จตามเป้า
  • ตัด API ที่เสียทิ้งอัตโนมัติ
  • ข้อดี: แม่นยำ ไม่เสียเวลายิงตัวที่ตายแล้ว

🐢 โหมดช้า (Slow)

ความเสี่ยง: ต่ำ 🟢
  • ยิงแบบใจเย็น มีดีเลย์กั้น
  • เหมือนคนกดเองมากที่สุด
  • ข้อดี: ปลอดภัย โอกาสโดนแบนน้อย
  • ข้อเสีย: ช้ามาก เหมาะกับเปิดทิ้งไว้ยาวๆ
